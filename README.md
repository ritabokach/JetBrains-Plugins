# Плагины JetBrains — каркас на Compose Multiplatform

Лабораторная 1, веха **В1 «Каркас»**. Курс кроссплатформенной разработки,
группа ПИН-252т.

Каталог плагинов [JetBrains Marketplace](https://plugins.jetbrains.com):
список, деталь плагина и страница вендора. Сети в этой вехе нет — список
живёт на моках, снятых с настоящего API.

Проект заведён визардом [kmp.jetbrains.com](https://kmp.jetbrains.com):
Android, iOS на Compose, Desktop, Web на Compose. Первый коммит — вывод
визарда без единой правки, дальше всё написано поверх.

## Запуск

```bash
./gradlew :desktopApp:run                        # ведущий таргет вехи
./gradlew :desktopApp:run -Plocale=en            # то же окно на английском
./gradlew :webApp:wasmJsBrowserDevelopmentRun    # web, бонусом
./gradlew :androidApp:assembleDebug              # Android
```

`-Plocale=en` подменяет только язык JVM, язык системы при этом не трогается.

iOS собирается только на macOS с Xcode — в вехе это бонус, и проверка на него
не смотрит.

## Как разложен код

```
shared/src/commonMain/kotlin/ru/bokach/plugins/
  domain/          модели и интерфейс каталога — не знает ни про UI, ни про сеть
  data/            моки и реализация репозитория. В В2 меняется только это
  catalog/         состояние, намерения и ViewModel экрана списка
  detail/          то же для детали плагина
  vendor/          то же для страницы вендора
  ui/model/        UI-модели и форматирование: сокращение загрузок, округление оценки
  ui/navigation/   бэкстек и хост Navigation 3
  ui/components/   переиспользуемые куски: карточка, чипы, шапка
  ui/screens/      три экрана, каждый рисуется из состояния
  composeResources/values, values-en   подписи интерфейса, две локали
```

Несколько решений, которые видно не сразу:

**Маршрут — объект.** `Screen` это sealed interface: `data object Catalog` и
`data class PluginDetail(pluginId)` / `VendorPage(vendorId)`. Опечататься
в аргументе не даст компилятор. Графа маршрутов в Navigation 3 нет — бэкстек
это обычный список, он лежит в `Navigator`, и ViewModel правят его, ничего
не зная про `NavDisplay`.

**Все три спецификации перехода заданы явно.** У `NavDisplay` значения по
умолчанию для не-Android таргетов в гугловском артефакте бросают
`NotImplementedError`, поэтому `transitionSpec`, `popTransitionSpec` и
`predictivePopTransitionSpec` прописаны руками. Заодно это и есть требование
вехи: назад экран должен уезжать не туда же, куда приезжал.

**UI-половина навигации взята у JetBrains** — `org.jetbrains.androidx.navigation3:navigation3-ui`.
Гугловская собрана только под androidJvm, jvm и linux_x64. Рантайм при этом
остаётся гугловский.

**Вниз в composable уходят состояние и колбэк**, а не ViewModel целиком:
отданная целиком ViewModel выводится как Unstable и убивает пропуск
рекомпозиции. Проверяется отчётом компилятора:

```bash
./gradlew :shared:compileKotlinJvm
grep -c "restartable skippable" shared/build/compose_compiler/*composables.txt
```

Все 17 composable проекта — `restartable skippable`.

**Цвет бейджа модели распространения не зависит от темы.** Это единственное
место, где цвет зашит мимо `MaterialTheme`, и это осознанно: зелёный там
означает «бесплатный», а не «светлое оформление».

## Про данные

28 записей в `data/MockCatalog.kt` сняты с `/api/searchPlugins` и
`/api/plugins/{id}` 25.09.2026. Поля доменных моделей названы так же, как в
ответах API, поэтому в В2 моки заменятся сетью, а не перепишутся. Длинные
описания подрезаны — всё остальное лежит ровно так, как отдал маркетплейс.

Данные каталога английские, и это не недоделка: локализуется интерфейс,
а не содержимое. Теги, имена плагинов и вендоров приходят из API как есть.

**Подвох темы.** `/api/searchPlugins` без параметра `search` список не
отдаёт. Сейчас пустой запрос означает «все записи» — на моках это бесплатно.
В В2 так не выйдет, и экрану придётся выбирать: подставлять запрос по
умолчанию или показывать «введите запрос». Сигнатура `searchPlugins(query)`
рассчитана на оба варианта и меняться не будет.

Иконки плагинов маркетплейс отдаёт по сети, поэтому вместо них — первая
буква имени. Появятся в В2 вместе с сетью.

## Чего здесь сознательно нет

Тема и язык живут в памяти сессии: на диск не сохраняется ничего. Адресная
строка браузера и deep links не трогаются, адаптива под ширину окна нет.
Тесты выключены — они приходят в В4. Всё это вехи В2–В4.
